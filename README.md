# กรอบงานเนื้อหา — ส่วนงานสื่อสารองค์กร สภาวิชาชีพบัญชี ในพระบรมราชูปถัมภ์

เอกสารสองชิ้นที่ทำงานคู่กัน สร้างจากโพสต์จริงบนเพจ TFAC.FAMILY จำนวน 461 โพสต์ ระหว่าง 1 มกราคม – 17 กันยายน 2569

| ไฟล์ | เนื้อหา |
|---|---|
| `index.html` | หน้าสารบัญ |
| `taxonomy.html` | ผังประเภทเนื้อหา — หลักการจัดประเภท 5 ข้อ, ประเภทเนื้อหา 22 ประเภทใน 4 หมวก, สัดส่วนทั้งปี |
| `risk.html` | เกณฑ์ความเสี่ยงเนื้อหา — นิยามความเสี่ยงสูง, เกณฑ์ตัดสิน 6 ข้อ, การแบ่งงาน 3 ระดับ, ผู้อนุมัติและ SLA |

## การเชื่อมกันของสองเอกสาร

รหัสประเภทเนื้อหา (ก1–ง6) ใน `taxonomy.html` เป็นคีย์เดียวกับที่ `risk.html` ใช้กำหนดระดับความเสี่ยง จึงบันทึกลงแบบฟอร์มสั่งงานเป็นสองฟิลด์ได้โดยตรง — “ประเภทเนื้อหา” และ “ระดับความเสี่ยง”

## การเผยแพร่

เป็นเว็บเพจ HTML แบบ static ไม่มี build step ไม่มี dependency นอกจากฟอนต์จาก Google Fonts เปิดใช้งานผ่าน GitHub Pages ได้ทันทีที่ **Settings → Pages → Source: Deploy from a branch → Branch: `main` / root**

## สถานะ

ร่างเพื่อการหารือภายใน ยังไม่ผ่านการอนุมัติ — ชื่อตำแหน่งผู้อนุมัติ รอบเวลาตรวจ และตัวชี้วัด เป็นข้อเสนอที่รอการยืนยันจากคณะกรรมการ
